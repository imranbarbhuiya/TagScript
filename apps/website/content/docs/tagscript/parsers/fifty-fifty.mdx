`5050` renders its payload on a coin flip. The other half of the time it renders nothing at all.

## For template authors

### Syntax

```tagscript
{5050:message}
```

### Examples

```tagscript
Hello!{5050: Nice to see you again.}
# Hello! Nice to see you again.
# Hello!
```

Because the tag renders an empty string on a miss, comparing it against empty gives you a plain coin flip:

```tagscript
I pick {if({5050:.}!=):heads|tails}
# I pick heads
# I pick tails
```

### Aliases

`5050`, `50`, `?`

## For developers

### Register the parser

<Tabs items={['ESM', 'CommonJS']}>
	```ts showLineNumbers tab="ESM"
	import { Interpreter, FiftyFiftyParser } from 'tagscript';
	const ts = new Interpreter(new FiftyFiftyParser());
	```
	```js showLineNumbers tab="CommonJS"
	const { Interpreter, FiftyFiftyParser } = require('tagscript');
	const ts = new Interpreter(new FiftyFiftyParser());
	```
</Tabs>

### Behaviour

The payload is required and no parameter is used. `parse` picks between `''` and the payload with `Math.random()`, so the odds are an even split and not configurable. For other odds, compare a [`range`](/tagscript/parsers/range) roll with [`if`](/tagscript/parsers/if-statement).
